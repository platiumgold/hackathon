# Система оптимизации распределенной электросети «Альфа»

Программный комплекс для управления перетоками мощности в распределительных сетях. Вычислительное ядро решает задачу максимизации суммарной переданной мощности при соблюдении физических ограничений участков сети и требований пропорционального отсечения заявок в условиях аппаратного дефицита пропускной способности.

## Концепция решения

Система спроектирована для работы в изолированных контурах без доступа к внешним сетям. Архитектура включает три независимых математических аппарата (графовые нейронные сети, стохастический поиск, обучение с подкреплением), что позволяет гибко адаптироваться к изменяющейся топологии графа и различным профилям нагрузки.

### Ключевые особенности

*   **Мультиалгоритмическое ядро**: Интеграция методов машинного обучения (GNN, PPO) и стохастической оптимизации (ACO) для надежного расчета графов любой сложности.
*   **Динамическое управление топологией**: Инструментарий для изменения направления перетоков на транзитных участках с целью оперативного устранения локальных перегрузок.
*   **Отказоустойчивый парсинг**: Модуль загрузки автоматически фильтрует непечатаемые символы в данных PDF и обрабатывает пустые лимиты, интерпретируя их как отсутствие физических ограничений.
*   **Итеративный балансировщик (Water-filling)**: Гарантирует соблюдение требования ТЗ о равнодоступности поставщиков. При дефиците пропускной способности участков мощности распределяются строго пропорционально исходным заявкам.

## Сравнительная характеристика алгоритмов

| Алгоритм | Теоретическая сложность | Рекомендуемый сценарий применения |
| :--- | :--- | :--- |
| **Графовая нейронная сеть (GNN)** | $\mathcal{O}(\text{Iter} \cdot \|R\| \cdot (\|E\| + \|V\| \log \|V\|))$ | Оптимизация пересекающихся потоков. Алгоритм выявляет скрытые зависимости маршрутов через эмбеддинги узлов, эффективно разводя конфликтующие заявки. |
| **Муравьиный алгоритм (ACO)** | $\mathcal{O}(\text{Iter} \cdot A \cdot \|V\| \cdot \Delta_{max} + \text{Iter} \cdot \|E\|)$ | Статические графы со сложными ветвлениями. Отыскивает глобальные оптимумы за счет накопления феромонной истории. |
| **Обучение с подкреплением (PPO)** | $\mathcal{O}(\text{Epochs} \cdot \text{Batch} \cdot \|E\| \cdot \|R\| \cdot K)$ | Условия выраженного дефицита мощности. Агент балансирует потоки, строго минимизируя дисперсию удовлетворенности потребителей. |

Где $A$ — суммарное количество агентов-муравьев, $\Delta_{max}$ — максимальная степень вершины графа, $K$ — размер выборки кратчайших путей.

## Стек технологий

*   **Вычислительное ядро**: Python, PyTorch, NumPy, NetworkX.
*   **Пользовательский интерфейс**: Streamlit, Plotly.
*   **Парсинг данных**: Pandas, PDFPlumber.

## Автономное развертывание

Система спроектирована для работы в изолированном контуре (Offline-режим). Вычислительное ядро не обращается к внешним API, что гарантирует безопасность загружаемых исходных данных.

Установка локальных зависимостей:
```bash
pip install -r requirements.txt
```

Инициализация программного комплекса:
```bash
bash run.sh
```

## Контроль качества

Проект покрыт модульными тестами, проверяющими выполнение физических инвариантов электросети:
1. Баланс схождения потоков (сохранение энергии в узлах).
2. Математическая корректность алгоритма пропорционального ограничения.
3. Соблюдение лимитов пропускной способности участков.

Запуск набора тестов:
```bash
pytest tests/ -v
```

## Соответствие критериям оценки

*   **Точность результатов**: Физика потоков рассчитывается в формате `float64`, что полностью исключает потерю точности. Встроенный порог отсечения микропотоков ($10^{-4}$) гарантирует стабильность и соответствие регламентному требованию округления до 3-х знаков после запятой.
*   **Соблюдение ограничений**: Реализован жесткий контроль пропускной способности (Capacity Constraint). Перераспределение мощности осуществляется алгоритмом Water-filling, который безупречно реализует требование пропорционального приема энергии.
*   **Информационная безопасность**: Искусственный интеллект (PPO, GNN) обучается и функционирует исключительно локально. Исключена любая передача схем и топологий третьим лицам, что полностью отвечает требованиям безопасности ТЗ.
